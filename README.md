# Ritual

Breathing as a practice — guided breathing with ambient sound, a breathing circle animation, and a companion for watch, Mac, and widgets.

## Concept

- Guided breathing sessions
- Ambient soundscapes
- Breathing circle animation
- Apple Intelligence support

## Targets

- iOS
- RitualMac
- RitualWatch
- RitualWidgets

## Stack

- SwiftUI
- Apple Intelligence
- WidgetKit
- watchOS
