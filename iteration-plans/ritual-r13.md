# Ritual R13 — Polish, App Store Listing, Launch Checklist

## Overview
Final polish pass before launch. Ensure every detail is intentional, create compelling App Store presence, and prepare for a thoughtful release.

## Pre-Launch Polish

### Visual Polish
- [ ] Review all animations for intentional feel (600-1200ms, ease-in-out)
- [ ] Ensure haptic feedback is subtle and meaningful
- [ ] Check all color combinations for accessibility (WCAG AA minimum)
- [ ] Test Dynamic Type at all sizes
- [ ] Verify dark mode support is complete
- [ ] Review all empty states are beautiful and encouraging
- [ ] Check loading states are calm, not jarring
- [ ] Test on actual devices (not just simulators)

### Copy Polish
- [ ] Review all button labels for warmth
- [ ] Ensure empty state messages are encouraging, not clinical
- [ ] Check error messages are gentle ("something went gently wrong" not "error")
- [ ] Verify notification copy is non-judgmental
- [ ] Review onboarding flow language

### Edge Cases
- [ ] Handle first launch with no data gracefully
- [ ] Handle 100+ intentions gracefully (pagination)
- [ ] Handle timezone changes
- [ ] Handle airplane mode gracefully
- [ ] Test what happens if user deletes and reinstalls

## App Store Listing

### Screenshots (6.7" and iPad)
- [ ] Morning intention hero shot
- [ ] Breathing session in progress
- [ ] Evening check-in
- [ ] Timeline/Insights
- [ ] iPad optimized layout

### App Store Text
- [ ] Name: "Ritual — Daily Intention Setting"
- [ ] Subtitle: "Shape your day with purpose"
- [ ] Description: Emotional, benefits-focused, no feature lists
- [ ] Keywords: intention, mindfulness, habit, daily, ritual, breathing, focus
- [ ] Privacy policy URL
- [ ] Support URL

### Preview Video
- [ ] 15-30 second atmospheric video
- [ ] Shows breathing animation
- [ ] Shows intention setting
- [ ] Ends with brand moment

## Launch Checklist

### Week Before Launch
- [ ] Final TestFlight build submitted
- [ ] External testers added for final feedback
- [ ] All social media assets ready
- [ ] Press kit prepared
- [ ] Support channels set up

### Launch Day
- [ ] App Store build goes live
- [ ] Social announcement posted
- [ ] Notify beta testers
- [ ] Monitor crash reports
- [ ] Monitor App Store reviews

### Post-Launch (Week 1)
- [ ] Respond to initial reviews
- [ ] Monitor analytics
- [ ] Fix any critical bugs
- [ ] Gather user feedback

### Post-Launch (Month 1)
- [ ] Review retention metrics
- [ ] Plan first content update
- [ ] Consider paid expansion features
